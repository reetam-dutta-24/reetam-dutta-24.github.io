SkillFlow

Mastery-first learning platform

Founder Live on AWS Sep 2026 – now

You only pass a stage when you can explain each idea in your own words and an AI reviewer agrees. No quizzes, no likes, no leaderboards.

  • Explain-back gate: each answer is reviewed by an LLM (Gemini). If the model is unavailable, nothing is saved, so the app never fakes a pass.
  • Dopamine Detox: a Detox Score that only verified learning can raise, with focus sessions and a weekly check-in.
  • RAG assistant: answers from SkillFlow's own help and catalog with cited sources, using pgvector (HNSW) and full-text search fused with Reciprocal Rank Fusion. For a stage you haven't passed, it gives hints instead of answers.
  • Accepted ideas become notes (Word or PDF export) and return for spaced recall; they also feed mastery, streaks and analytics.
  • Built on Next.js Server Components and Server Actions, PostgreSQL with Prisma, Auth.js (Google OAuth), Redis rate limiting and Stripe subscriptions.
  • Runs on AWS EC2 with Docker Compose and Caddy (HTTPS), nightly database backups to S3 and uptime monitoring.

EntertainVerse

AI entertainment hub for anime, shows, K-dramas, films and music

Runs on AWS Jul – Oct 2026

People pay for several streaming apps and still lose 20 minutes scrolling. EntertainVerse answers what to watch, why, and in what order.

  • Hybrid recommender: explicit taste, Gemini embeddings and collaborative filtering, with a reason on every card. In an offline leave-one-out test it scored MRR@20 0.350 against 0.203 for a popularity baseline.
  • AI mode and RAG: turns your mood into a watch or listen plan that fits your weekly hours, spoiler-safe "catch me up" recaps grounded in episode guides, and an in-app assistant with cited sources.
  • Social and realtime: AI Match rooms, synced watch and listen parties where the host can share their screen, WebRTC voice rooms, and live chat and DMs with typing and online status.
  • Built to scale: two EC2 servers behind an AWS Application Load Balancer, with a Redis Socket.IO adapter and shared party state, S3 uploads, health checks and graceful shutdown. Party members reconnect to the other server without losing their place.
  • AI-assisted admin CMS that imports titles and music from TMDB, AniList, Deezer, MusicBrainz and Apple Music, with an AI review before publishing.

CourtKinetics

Badminton performance analytics with pose estimation

In progress Sep 2026 – now

Instead of generic match stats, it tests four specific questions: does reaction timing predict who wins the point, do unforced errors have warning signs, does doubles court coverage predict lost rallies, and how often are attacking chances converted?

  • Python pipeline (OpenCV, MediaPipe) writes 33 body landmarks per frame, using each frame's own timestamp because the clips have variable frame rates.
  • On a 60-second test clip: about 97% of frames detected, with ankle and knee visibility scores of 0.92–0.97.
  • Because MediaPipe tracks only one person, added a YOLO-Pose + ByteTrack extractor that keeps a persistent ID for each player, plus overlay scripts to check tracks visually.

King County Home Value Predictor

Explainable ML valuation, from raw data to a deployed API

Live Sep – Oct 2026

Every estimate comes with its reasons: a price range, the SHAP drivers behind it, comparable nearby sales and a map.

  • Engineered 100+ features from 21,613 home sales, including distances to key places, KMeans location clusters and PCA that compresses 50 landmark distances into 3 components.
  • Target encoding computed only on the training split to avoid leakage; experiments tracked in MLflow.
  • FastAPI prediction service on Render and a multi-page Streamlit app on Streamlit Cloud.
