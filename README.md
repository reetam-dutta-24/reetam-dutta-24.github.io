## How it's built

- A single `index.html` file: hand-written HTML, CSS and a little vanilla JavaScript
- No framework, no build step, no dependencies
- Fonts: Bricolage Grotesque, Instrument Sans and JetBrains Mono from Google Fonts
- Light and dark themes that follow your device setting
- Responsive from phone to desktop, with keyboard focus states and reduced-motion support
- Hosted on GitHub Pages

## Run it locally

```bash
git clone https://github.com/reetam-dutta-24/reetam-dutta-24.github.io.git
cd reetam-dutta-24.github.io
```

Then open `index.html` in a browser. Nothing to install.

## Deploy

Push to `main`. GitHub Pages publishes the site automatically, usually within a minute or two.
